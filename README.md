# **AdvanceOOPwithLv - Laravel Traits (Trait Branch)**

This repository explores **advanced Object-Oriented Programming (OOP) in Laravel**, focusing on **Traits** to promote code reusability and cleaner architecture.

## **📌 What’s Covered?**

-   **Laravel Traits** – How to create and use Traits effectively.
-   **Code Reusability** – Sharing methods across multiple classes.
-   **Implementation in Controllers & Models** – Practical examples in Laravel.

## **📂 Project Structure**

-   **`app/Traits/`** → Contains reusable Traits.
-   **`app/Http/Controllers/`** → Uses Traits in controllers.
-   **`app/Models/`** → Implements Traits in models.
-   **`routes/web.php`** → Defines application routes.
-   **`resources/views/`** → Blade templates for UI.

## **🚀 How to Get and Set Up the Trait Branch**

### **Clone the Repository & Switch to Trait Branch**

```bash
git clone https://github.com/mustanjid/AdvanceOOPwithLv.git
cd AdvanceOOPwithLv
git checkout Trait  # Switch to the Trait branch
```

### Install Dependencies

```bash
composer install # Switch to the Trait branch
```

### Set Up Environment

```bash
cp .env.example .env
php artisan key:generate
```

Run the project!
